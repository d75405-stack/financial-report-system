# 里辦公處 LINE 官方帳號系統

用 LINE 官方帳號管理里長工作團隊，並提供里民服務。

| 功能 | 誰用 | 怎麼用 |
|---|---|---|
| 成員綁定 | 工作人員 | 點圖文選單「工作人員綁定」輸入邀請碼，或在聊天室輸入 `綁定 邀請碼 姓名` |
| 回報狀況 | 工作人員 | 點「回報」開表單（可附照片、定位），或直接輸入 `回報 內容` |
| 推播宣達 | 里長 | 管理後台發給全體工作人員、特定組別或所有好友 |
| 公告查詢 | 所有人 | 點「最新公告」（回覆訊息不計推播則數） |
| 律師諮詢 | 里民 | 點「律師諮詢」選時段預約；前一天 18:00 自動提醒 |
| 雲端備份 | 自動 | 每天 02:00 把資料備份並分類到指定的 Google 雲端硬碟資料夾 |
| 管理後台 | 里長 | 處理回報、發推播、管理律師時段與成員、立即備份 |

新回報、新預約會自動推播通知職務為「里長」或「管理員」的成員。

## 北屯鬧起來 每日報名快報

每天中午 12 點左右，系統查詢活動網站（ccs2024taiwan.pages.dev）的報名人數、剩餘名額、未繳費人數，推播到聯辦群組並 @所有人，附上各活動報名連結請大家幫忙推廣。訊息只包含人數，不含任何個資。

- 設定：試算表選單 **LINE 系統 → 設定每日報名快報（聯辦群）**，輸入活動網站的匯出密碼（EXPORT_KEY，用來統計未繳費），可選擇立即發送一次測試。
- 預覽：**LINE 系統 → 預覽報名快報**（不會發送）。
- 群組 ID 預設為聯辦群，可用指令碼屬性 `REPORT_GROUP_ID` 更改。

## 律師諮詢開關

律師諮詢預設**尚未開放**：里民點「律師諮詢」、輸入「我的預約」、開啟預約頁或問全全時，都會回覆「尚未開放，敬請期待」。準備好時段後，在試算表點 **LINE 系統 → 開放／關閉律師諮詢** 即可開放（指令碼屬性 `LAWYER_OPEN`）。

## 小幫手「全全」

**全全只在群組服務。** 個人私訊輸入「全全…」或「說明」時，只會回覆一則罐頭訊息（可在試算表 **LINE 系統 → 修改私訊罐頭訊息** 更改），由專人後續回覆。

在群組輸入「全全」開頭的訊息，小幫手就會回應，並附上快速按鈕：

| 誰 | 可以說 | 做什麼 |
|---|---|---|
| 所有人 | `全全`、`全全 說明` | 使用說明 |
| 工作人員 | `全全 我的回報` | 自己最近回報的處理進度 |
| 里長／管理員 | `全全 狀況` | 整體分析：回報數量與類別、最久未完成、律師諮詢預約率、推播則數、備份狀態與建議 |
| 里長／管理員 | `全全 待處理` | 未完成的回報清單（由舊到新） |
| 里長／管理員 | `全全 預約` | 未來 7 天的律師諮詢名單 |
| 里長／管理員 | `全全 備份` | 立即備份到雲端硬碟，完成後通知（用 1 則推播） |

全全的回覆都用 LINE 的「回覆訊息」，不計推播則數。

### AI 問答（選用）

設定 Anthropic API 金鑰後，「全全 + 一般問題」（例如「全全 陀螺賽在哪裡比？」）會交給 Claude 回答：

- 只根據試算表「**知識庫**」工作表的內容回答；沒有的資訊會請對方留言由真人回覆。第一次開啟時會自動填入北屯鬧起來活動與里辦服務的公開資訊，請自行檢查修改。
- 每次問答記錄在「**AI問答紀錄**」工作表，可據此補充知識庫。
- 短指令（6 個字以內，例如「全全 備份」）仍走固定功能。
- 每人每 6 小時最多 15 題；模型預設 `claude-opus-5-5`，可用指令碼屬性 `AI_MODEL` 更換。
- 不評論其他候選人或政治議題、不提供個別法律意見（引導使用律師諮詢）。
- 設定：試算表選單 **LINE 系統 → 設定全全 AI 問答**，貼上在 <https://platform.claude.com> 建立的 API 金鑰；輸入「關閉」可停用。

## 設定（約 15 分鐘，共 6 步）

開始前請準備：
- 一個 Google 帳號，而且這個帳號擁有（或可以編輯）備份用的雲端硬碟資料夾
- LINE Developers 裡的 **Messaging API channel**（官方帳號開啟 Messaging API 後就會有）

### 第 1 步：建立試算表

用上面那個 Google 帳號打開 <https://sheets.new>，檔名改成「里辦 LINE 資料」。

### 第 2 步：貼上程式碼並部署

1. 試算表選單 **擴充功能 → Apps Script**。
2. 刪掉編輯器裡原本的內容。打開 [`apps-script/Code.gs`](apps-script/Code.gs)，按程式碼右上角的 **複製（Copy raw file）** 圖示，回到編輯器貼上，按 💾 儲存。
   - 不要從瀏覽器「翻譯」過的頁面複製，程式碼會被加入多餘的空格而無法執行。
3. 右上角 **部署 → 新增部署作業** → 點齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按 **部署**，依畫面授權：
   - 出現「Google 尚未驗證這個應用程式」時，點「進階 → 前往（不安全）」，因為這是你自己的程式。
   - 權限清單請勾 **全選**，少勾任何一項，LINE 回覆或雲端備份都會失敗。
5. 複製 **網頁應用程式網址**（結尾是 `/exec`），先貼在記事本。

### 第 3 步：建立 LIFF（讓表單能在 LINE 裡開啟）

1. [LINE Developers](https://developers.line.biz/console/) → 選官方帳號所在的 Provider → **Create a new channel → LINE Login**。
   - 一定要和 Messaging API channel 放在**同一個 Provider**，否則系統認不出是同一個人。
2. 進入這個 LINE Login channel → **LIFF** 頁籤 → **Add**：
   - Size：**Full**
   - Endpoint URL：`https://d75405-stack.github.io/financial-report-system/line-bot/web/liff.html`
   - Scopes：勾選 **openid**、**profile**
   - Add friend option：**On (Normal)**
3. 複製 **LIFF ID**（例如 `1651234567-AbCdEfGh`），貼在記事本。
4. 回到 channel 上方，把狀態從 Developing 改成 **Published**。

### 第 4 步：網頁上線

把網頁應用程式網址和 LIFF ID 填進 `web/config.js`，推送到 `master` 分支，GitHub Pages 會在一兩分鐘內自動上線（可以請 Claude 代勞）。

### 第 5 步：一鍵設定

先把這 4 個值準備在記事本（設定視窗開著的時間有 6 分鐘上限）：
1. **Channel access token**：Messaging API channel → Messaging API 頁籤最下方。若是空的，先按 **Issue** 產生。
2. 第 2 步的網頁應用程式網址
3. 第 3 步的 LIFF ID
4. **備份資料夾網址**：在雲端硬碟打開資料夾，複製網址列。資料夾的「一般存取」請先改成 **限制**，設成「知道連結的任何人」時系統會拒絕寫入，以保護個資。

然後：
1. 回到試算表，**重新整理頁面**，上方會出現 **LINE 系統** 選單。
2. 點 **LINE 系統 → 一鍵設定**，依序貼上 4 個值。貼錯會當場提示並請你重貼；按取消則什麼都不會改。
3. 第一次會要求授權（同樣請勾 **全選**），授權後再點一次「一鍵設定」。

完成後會自動：建立工作表、產生管理密碼和邀請碼、設定每日提醒和備份排程、**設定 LINE webhook 網址**、**建立圖文選單**、做第一次備份，並顯示結果。

### 第 6 步：調整 LINE 官方帳號的回應設定

[LINE 官方帳號管理後台](https://manager.line.biz/) → **設定 → 回應設定**：
- Webhook：**開啟**
- 自動回應訊息：**關閉**
- 加入好友的歡迎訊息：**關閉**（系統會自己送歡迎訊息，避免重複）
- 聊天：開啟（機器人不認得的訊息會留給里辦人員手動回覆）

### 完成後

- 管理後台：<https://d75405-stack.github.io/financial-report-system/line-bot/web/admin.html>，密碼在 **LINE 系統 → 查看設定狀態**（請勿外流）。
- 里長自己先點圖文選單「工作人員綁定」，再到管理後台 → 成員，把自己的職務改成「里長」，之後就會收到新回報與新預約通知。
- 只有第一次執行設定的 Google 帳號能重新執行「一鍵設定」，避免其他共用試算表的人多建一組排程。

## 雲端硬碟備份

每天凌晨 2 點自動執行，也可以在管理後台總覽按「立即備份」，或從試算表選單 **LINE 系統 → 立即備份到雲端硬碟**。

```
備份資料夾/
├─ 每日備份/2026/2026-10/里辦LINE資料_2026-10-04_0200.xlsx   ← 整份資料的歷史快照
├─ 最新資料/                                                  ← 每次覆蓋成最新內容
│   ├─ 工作人員/工作人員名單.csv
│   ├─ 回報/全部回報.csv
│   │   ├─ 依類別/道路路燈.csv、環境清潔.csv …
│   │   └─ 依狀態/待處理.csv、處理中.csv、已完成.csv …
│   ├─ 推播公告/推播公告.csv
│   └─ 律師諮詢/律師時段.csv、全部預約.csv
│       └─ 依月份/2026-10.csv …
└─ 回報照片/道路路燈/2026-10/R2610….jpg                        ← 回報時直接存到這裡
```

- CSV 用 Excel 直接開啟中文不會亂碼，電話開頭的 0 也會保留。
- 「依類別／依狀態／依月份」資料夾每次都會重寫；試算表裡已經沒有資料的分類檔會移到垃圾桶，避免留下過時資料或已刪除的個資。
- 每日快照會一直累積，不會自動刪除；太舊的月份可以自行刪除（刪除試算表的資料列，不會刪掉以前的快照和照片）。
- 備份資料夾若被改成「知道連結的任何人」或移到垃圾桶，系統會暫停寫入，回報照片改存到私人資料夾「LINE 回報照片」，管理後台會顯示原因。
- 備份失敗時一定會推播通知里長（不受 `NOTIFY_ADMINS` 影響），管理後台總覽也會顯示錯誤原因。

## 費用與則數

- Google Apps Script、試算表、雲端硬碟、GitHub Pages：免費（雲端硬碟用的是該帳號的容量）。
- LINE 官方帳號：**回覆訊息不計費**；**推播**（宣達、通知里長、預約提醒、通知回報人、備份失敗通知）依收件人數計入每月則數。免費方案額度有限，管理後台總覽會顯示本月已用則數。
- 省則數：一般公告請里民點「最新公告」查詢，只有緊急事項才發給所有好友。

## 安全與個資

- **備份資料夾必須設成「限制」**：備份裡有工作人員電話、律師諮詢內容與照片。資料夾設成「知道連結的任何人」時，系統會拒絕寫入並在一鍵設定與管理後台顯示原因。
- **管理後台**：用 `ADMIN_TOKEN` 登入；外流時請在 Apps Script **專案設定 → 指令碼屬性** 更換。
- **LIFF 頁面**：每次呼叫都會向 LINE 驗證身分，無法冒用他人。
- **Webhook**：Apps Script 讀不到 `X-Line-Signature` 標頭，所以無法驗簽。會改變資料的動作（綁定、文字回報）都是先回覆、回覆成功才寫入資料；reply token 只有 LINE 平台會發出，偽造的請求會回覆失敗，也就不會寫入。
- **CSV 防公式注入**：回報內容開頭若是 `=`、`+`、`-`、`@`，備份時會加上 `'`，避免用 Excel 開啟時被當成公式執行。
- **個資保存**：律師諮詢會收集姓名、電話與問題內容，請依個人資料保護法妥善保管並定期清除。

## 修改程式

### 自動更新（GitHub Actions）

`line-bot/apps-script/` 有變更並推送到 `master` 時，`.github/workflows/apps-script.yml` 會用 clasp 把程式推送到 Apps Script，並更新現有部署（網址不變）。需要的一次性設定：

1. 到 <https://script.google.com/home/usersettings> 開啟「Google Apps Script API」。
2. 在自己的電腦執行 `npm install -g @google/clasp@2.4.2` 和 `clasp login`（Windows PowerShell 請用 `npm.cmd`、`clasp.cmd`）。
3. 把產生的 `~/.clasprc.json` 全部內容存成 GitHub secret `CLASPRC_JSON`。

專案 ID 在 `apps-script/.clasp.json`，部署 ID 在 workflow 的 `DEPLOYMENT_ID`。新版程式需要新權限時，仍要在試算表點一次「一鍵設定」授權。

### 手動更新


- 改 `Code.gs` 後，到 Apps Script 貼上新版並儲存，再到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署**，網址會維持不變。接著在試算表點一次 **LINE 系統 → 一鍵設定**（全部留空按確定即可），新版若需要新權限會在這時要求授權。
- 只有第一次執行設定的帳號能重新設定或從選單備份；要換帳號時，刪除指令碼屬性 `SETUP_OWNER` 再由新帳號執行。
- 回報類別、狀態、通知對象：`Code.gs` 開頭的 `REPORT_CATEGORIES`、`REPORT_STATUSES`、`ADMIN_ROLES`
- 關閉新回報／新預約通知里長：指令碼屬性加 `NOTIFY_ADMINS` = `false`（備份失敗通知不受影響）
- 圖文選單圖片：`web/richmenu.png`（2500×1686，六格）
- `apps-script/appsscript.json` 是給 clasp 等工具用的設定檔，用網頁編輯器設定時不需要。

## 律師資料

- 試算表「律師資料」工作表存放三位律師的介紹（姓名、職稱、事務所、專長、經歷、簡介、照片）。
- 照片放在 `line-bot/web/lawyers/`，資料欄位 photo 填檔名即可。
- 狀態「準備中」不會顯示；改成「上架」且律師諮詢開放後，預約頁才會出現律師介紹。
- 地點確定前請維持「LINE 系統 → 開放／關閉律師諮詢」為關閉。
- 2026-10：週二（陳沂裴律師，几乎食間 Jeff's kitchen）10/20 起開放預約，週三、週四地點確認中。

### 自動開時段與預約規則

- 「律師資料」的 bookFrom 欄填了開放日（例 2026-10-20）的律師，系統會從那天起每週固定那天自動開時段：依 schedule（例「每週二 18:00–20:00」）切成每 30 分鐘一格、每格 1 位，一晚 4 個時段，地點帶入 place。
- 每天排程會補到往後約 5 週；在管理後台刪掉的時段（例如放假）不會再自動長回來。
- 需提前 7 天預約，不開放當天預約（`LAWYER_BOOK_LEAD_DAYS`）。
- 有可預約時段的律師，介紹卡片才有「預約時段」按鈕；其他律師顯示「尚未開放預約」。
- 週三、週四地點確定後：由 Claude 在程式的 LAWYER_SEED 填上 place、placeUrl、bookFrom 並推送即可。

## 好友紀錄

- 有人加入或封鎖官方帳號時，會記錄在試算表「好友紀錄」工作表（時間、LINE 名稱、動作），每天也會備份到雲端硬碟「好友」資料夾。

## 私訊關注（取消報名等）

- 私訊出現「取消、退出、退費、不參加、無法參加、改期、放棄…」等字眼時，記到試算表「私訊關注」，並用 LINE 通知里長（職務為里長／管理員的人；都沒有時通知最早加入的工作人員）。
- 里民傳「…報名確認|姓名|…」時記到「報名確認紀錄」，通知裡會附上這個人報名過的活動。
- 只記錄、不自動回覆，也不會自動取消報名；請到活動後台處理後在 LINE 回覆對方。處理完可在「私訊關注」的 handled 欄填「已處理」。
- 關鍵字可用指令碼屬性 WATCH_KEYWORDS（逗號分隔）自訂。

## 活動報名名單同步

- 每小時自動把活動網站四個活動（陀螺賽、變裝、手工皂、彩繪提袋）的報名名單複製到試算表「活動報名名單」工作表，可直接搜尋姓名或電話確認有沒有報名。
- 只複製活動、場次/梯次、編號、姓名、同行者、電話、繳費、報名狀態、報名時間；不含身分證字號、Email、生日、住址。
- 網站暫時連不上時保留上一次的名單。想馬上更新：LINE 系統 → 立即同步活動報名名單。
- 正本仍是活動網站後台，這份只是查詢用的副本。

## 律師群組

- 里長在法律諮詢群組輸入「全全 設為律師群組」，之後律師諮詢的通知都會發到這個群組（只有里長能設定）：
  - 有人預約：日期、時段、律師、預約人姓名電話、諮詢類別、問題簡述、該時段剩餘名額
  - 有人取消（本人或工作人員取消）
  - 每次諮詢前一天晚上 6 點：隔天各時段的預約名單
- 查詢預約狀況：在律師群組直接輸入「預約狀況」（或「預約名單」「查詢預約」，加不加「全全」都可以），會列出今天起每一場的預約人、電話、類別與空的時段；只看某天輸入「預約狀況 10/20」。只有律師群組能查，其他群組和私訊都看不到名單。
- 停止：在群組輸入「全全 取消律師群組」。
